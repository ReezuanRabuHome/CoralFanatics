# Source assets (drop folder)

Put the real Coral Fanatics brand and photography files here. They are the source of truth for the design.

```
assets/
├─ brand/          logo source files (AI / EPS / SVG / PDF preferred; highest-res PNG otherwise),
│                  any brand guidelines, signage/printer colour codes
└─ photography/    shop photos (originals, unedited if possible)
   ├─ hero/        wide display-tank shots
   ├─ corals/      SPS / LPS / mushroom examples and individual specimens
   ├─ fish/
   ├─ inverts/
   ├─ dry-goods/
   └─ shop-team/   interior and team
```

- See `docs/planning/photography-spec.md` for sizes, naming and the minimum shot list.
- Large photo collections may be better shared via a cloud-drive link than committed to Git. Commit only the selected images used for the design prototype.
- No AI-generated or stock imagery here.
